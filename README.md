## 📚 Day 1 — React Fundamentals

### What I Learned

- **React Components:** Understanding how a component represents a reusable piece of UI.
- **`function App()`:** Defining a React component using a JavaScript function.
- **`return`:** Returning JSX from a component.
- **JSX:** Writing HTML-like syntax inside JavaScript.
- **Fragments (`<>...</>`):** Grouping multiple JSX elements without adding an extra DOM element.
- **`className`:** Applying CSS classes in JSX.
- **`export default`:** Exporting a component so it can be imported into another file.
- **Tailwind CSS v3:** Learning the setup process and utility-first styling approach.

### 🧩 My First React Component

```jsx
function App() {
  return (
    <>
      <h1>My React Journey</h1>
      <p>Day 1: I'm learning React from scratch.</p>
      <p>I'm learning React step by step.</p>
      <button>Start Learning</button>
    </>
  );
}

export default App;
```

### 🔍 How It Works

1. `function App()` defines the component.
2. `return` provides the JSX that describes the UI.
3. JSX contains a heading, paragraphs, and a button.
4. `export default App` makes the component available for import elsewhere.
5. React renders the component through the application's entry point.

## 🎨 Styling with Tailwind CSS v3

Tailwind CSS lets me style elements using utility classes directly in JSX.

Example:

```jsx
<h1 className="text-3xl font-bold text-blue-700">
  My React Journey
</h1>
```

- `text-3xl` — large text size
- `font-bold` — bold font weight
- `text-blue-700` — blue text color

I'm learning how utility classes help create clean and responsive user interfaces.

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- A code editor such as VS Code

### Installation

Clone the repository:

```bash
git clone https://github.com/Poonam-D07/react-journey-from-zero.git
```

Navigate to the project folder:

```bash
cd react-journey-from-zero
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
